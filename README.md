# THE PULSE // 12C
### Real-time 12-City Typography Installation

**THE PULSE // 12C** は、世界12都市から届くリアルタイム・ニュースと気象データを、巨大なタイポグラフィとして身体的に浴びるためのデータ・アート・ビューワーです。かつてダムタイプや原田大三郎氏が試みた「情報の現象化」を、現代のライブデータとブラウザ技術を用いて再解釈したインストラクション・ワークです。

---

### 🚀 Key Features

- **12-City Synchronized Feed**: 世界の主要12都市（東京、ロンドン、ニューヨーク、アイスランド、サンパウロ等）のライブニュース、気温、降水確率をリアルタイムに同期。
- **Sixtyfour Convergence Typography**: デジタル回路の深層や電光掲示板の質感を思わせるドットフォントを採用。情報の「硬度」と「事実感」を強調します。
- **Dynamic Impact Scaling**: ニュースの文字数に応じて、画面からはみ出さない限界までフォントサイズを自動膨張。短い数値は壁一面を占拠する巨大なモニュメントに、長い見出しは圧倒的な情報の壁となります。
- **Minimalist Aesthetic**: 情緒的な可変演出や装飾を一切排除。漆黒の背景に浮かぶ白い光（データ）のみで構成された、ストイックな没入体験。
- **Zero-Key Architecture**: APIキーを必要としない公開ソースのみを利用。高額請求やキー漏洩のリスクなく、誰でも安全に環境を構築可能です。

### 💻 Recommended Environment

- **Browser**: Google Chrome (Latest version)
- **Hardware**: Apple Silicon Mac (M1 or later)
- **Display**: 大型プロジェクターによる壁面投影、または4K以上の大型ディスプレイでの鑑賞を推奨。

### 📖 How to Use

1. `index.html` をブラウザで開きます。
2. データの同期が完了すると、自動的に世界12都市の巡回が始まります。
3. **[F] キー** を押し、フルスクリーンモードで鑑賞してください。
4. 約8秒ごとに「ニュース」「気温」「降水確率」のパルスが切り替わり、1セットごとに都市がローテーションします。

### ⚠️ Precautions

- **Internet Connection**: リアルタイムデータを取得するため、常時ネットワーク接続が必要です。
- **Data Source**: ニュースデータは BBC World News の公開フィードを、気象データは Open-Meteo を使用しています。
- **Source Label**: 画面上にデータの出典（SOURCE: BBC）が自動表示されます。これは情報のドキュメンタリーとしての裏付けを意図したものです。
